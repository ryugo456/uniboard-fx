# UniBoard FX

エフェクター（ギター用ペダル）を自作するときの、**回路図 → ユニバーサル基板** への置き換えをパソコン上で行うツールです。
基板の配線が回路図どおりかを自動で確かめ、ギターの音がその回路を通るとどう変わるかをシミュレーションして聴けます。

ブラウザだけで動きます。インストールや外部ライブラリは不要です。

## 主な機能

- **回路図の取り込み**：SPICE ネットリスト（LTspice / KiCad の書き出しや手書き）と、draw.io の電気回路図形で描いた `.drawio` を読み込み、部品リスト（No / Name / Type / Value）を表示。CSV 出力も可能
- **基板エディタ**：2.54mm ピッチの穴にスナップして部品を配置。リード間隔は両端をドラッグ、本体寸法・トランジスタのピン配置はサイドバーで編集。穴と穴を配線ツールでつなぐ。選択・範囲選択・移動・回転・コピー＆貼り付け・元に戻す・ズーム・ハンドツールなど、draw.io に近い操作
- **回路図エラー判定**：基板の配線を回路図と照合し、未接続・ショート・値違い・極性の逆・ピン配置の間違い・同じ穴に複数の足・基板からのはみ出し・未配置などを表示。エラー箇所は基板上に赤丸で表示し、未配線の接続は点線（ラッツネスト）で示す
- **SoundCheck（音のシミュレーション）**：内蔵のギター音、または読み込んだ音声ファイルを回路に通して波形表示・再生。回路図どおりの音と基板の配線どおりの音を比べて「同じ音か」を自動判定し、手本の録音（ライン録音）との音色・歪み感の比較もできる
- **保存**：複数のシートをまとめて `.ubfx`（JSON）で保存・読み込み

## 起動方法

`index.html` をダブルクリックして、ブラウザで開きます（Chrome または Edge を推奨）。

うまく開けない場合は、このフォルダでローカルサーバーを立ててから開いてください。

```bash
python -m http.server 8765
```

ブラウザで `http://localhost:8765` を開きます。

## 使い方の流れ

1. **回路図を取り込む**：File → 回路図(ネットリスト)を取り込む。Tools → サンプル回路 で試すこともできます
2. **部品を置く**：Parts List の行を基板へドラッグ（ダブルクリックでも可）。「一括配置」で全部並べることもできます
3. **配線する**：`W` キー（配線ツール）で穴から穴へドラッグ
4. **基板の外へつなぐ**：電源・ジャック・ポットへの配線位置に「外部端子」を置き、ネット名（IN / OUT / VCC / GND など）を設定
5. **エラー判定を確認**：すべて解消すると「回路図どおりに配線されています」と表示されます
6. **SoundCheck**：右上のボタンで音を計算し、回路図の音・基板の音を聴き比べます

詳しい操作とショートカットは、アプリの Help → 使い方とショートカット にあります。

## 回路図の形式

### SPICE ネットリスト

1 行に部品 1 個を、`部品名 つながる先… 値または品番` の順に書きます。1 行目はタイトルです。

```
* LPB-1 ブースター
V1 VCC 0 9
VIN IN 0 SIN(0 0.3 440)
C1 IN B 100n
R1 VCC B 430k
R2 B 0 43k
Q1 C B E 2N5088
R3 VCC C 10k
R4 E 0 390
C2 C OUT 100n
RPOT1 OUT 0 100k
```

- 部品名の頭文字で種類が決まります：R 抵抗、C コンデンサ、L コイル、D ダイオード、Q トランジスタ、J JFET、X オペアンプ、V 電源・入力
- GND は `0`。`SIN(...)` 付きの V がギター入力になります
- 値の単位は `k` `u` `n` `p` `Meg`、`4k7` も可。**`1M` は SPICE の決まりで「1 ミリ」** なので、1MΩ は `1Meg` と書きます
- ピンの順番：D はアノード・カソード、Q は C・B・E、J は D・G・S、X は IN+・IN−・V+・V−・OUT・品番
- 名前に `POT` を含む抵抗は、基板の外の部品（ポット）として扱います

LTspice は View → SPICE Netlist の内容を、File → ネットリストを貼り付けて取り込む に貼り付けるのが手軽です。

### draw.io

draw.io の **Electrical** ライブラリの図形で描き、線の端を部品の接続点にくっつけた回路図を読み取れます。部品番号と値（例：`R1 10k`、`Q1 2N5088`）は部品のラベルや近くのテキストから読みます。

## テスト

[Node.js](https://nodejs.org/) があれば、依存パッケージなしで実行できます。

```bash
node test.js
```

回路シミュレータ、基板と回路図の照合、基板の配線どおりの音の計算、音色比較、draw.io の読み取りを確認します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | 画面の操作（基板エディタ、パネル、音、ファイル） |
| `sim.js` | SPICE ネットリストの解析と回路シミュレータ（MNA 過渡解析）、音色分析 |
| `check.js` | 部品の定義、基板の導通解析、回路図との照合、基板からのネットリスト生成 |
| `drawio.js` | draw.io 回路図から SPICE ネットリストへの変換 |
| `test.js` | 自己テスト |

## 制限事項

- オペアンプは理想に近いモデル（電源電圧で頭打ち）で、反応速度（スルーレート）や周波数特性は再現しません
- 5 端子（オペアンプ）以外のサブ回路は読み飛ばします
- 配線の抵抗や浮遊容量は計算に含めません
- 回路図の画像からの自動読み取りはできません（画像は参照表示のみ）
- 計算はブラウザのメインスレッドで行うため、長い音声ほど時間がかかります（入力は最大 10 秒）
